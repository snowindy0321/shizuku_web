Shizuku WebUSB 啟動器

完全在瀏覽器端執行，安全無虞
無法在本地檔案模式運行 WebUSB API 規定必須在 https:// 或 http://localhost 環境下才能運作。請將此網頁部屬至伺服器。
瀏覽器不支援 您的瀏覽器不支援 WebUSB 功能。請使用 Windows、Mac 或 Linux 電腦端的 Google Chrome 或 Microsoft Edge 瀏覽器。
1

準備手機

進入手機設定，開啟「開發者選項」並啟用「USB 偵錯」。

2

連接電腦

使用傳輸線將手機連接至這台電腦，如有彈出 USB 用途請選擇「僅充電」或「傳輸檔案」。

3

一鍵啟用

點擊下方按鈕，選擇您的設備，並在手機畫面上勾選「允許 USB 偵錯」。

執行日誌 
等待操作中... 請先確認手機已連接至電腦。
